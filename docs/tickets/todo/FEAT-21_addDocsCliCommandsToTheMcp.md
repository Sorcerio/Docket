# Add Docs CLI Commands to the MCP

Originally, the `docs` commands in the CLI tree were intended to be a user focused tool.

However, in using Docket on various projects it appears agentic systems would prefer to assist in keeping documentation like the `roadmap.md` up to date.
As such, we should add the `docs` tree to the MCP directly.
