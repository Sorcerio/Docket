# Add Status to Graph Scope

`graph`'s `SCOPE` is defined as: "What to scope to, read from its own shape: a ticket id, or a key. The flags below are the same two, named explicitly."

We need to add the ability to scope by `status` (todo, etc) to the `SCOPE` selection.
