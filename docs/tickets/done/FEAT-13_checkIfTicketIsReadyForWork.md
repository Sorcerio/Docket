# Check if Ticket is Ready For Work

Add a `ready` check for tickets that asserts `true` or `false` indicating if the ticket is ready for work.

Ready for work means that all pre-requisites are completed.

Consider adding to the MCP as well to make the check explicit rather than through a logical assertion by the LLM.
